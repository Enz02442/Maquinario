# Maquinário - Devisate construções

Aplicação cross-platform desenvolvida localmente utilizando

-  **[Visão Geral do Projeto](Home/)**


O protótipo desenvolvido no Figma foi baseado em algumas lojas de maquinários já existentes, como a Makita, que serviu como uma das principais referências para o desenvolvimento do projeto. No entanto, também buscamos utilizar nossa criatividade, combinando um design original com eficiência e velocidade, visando proporcionar uma experiência prática e agradável aos usuários.


-  **[Modelo do site feito no Figma](Link_Figma/)**


Utilizamos o amarelo-alaranjado como uma das principais cores da interface, pois essa tonalidade está diretamente associada aos maquinários, que em sua maioria apresentam essa cor. Dessa forma, trouxemos essa identidade visual para representar nossos produtos.

Também utilizamos cores clássicas, como branco e preto, para transmitir uma aparência mais profissional e manter uma interface limpa, equilibrada e sem excesso de cores, proporcionando uma melhor experiência ao usuário.



Estamos desenvolvendo o projeto gradualmente, avançando a passos curtos, mas buscando tomar decisões cada vez mais assertivas e criativas. Nosso objetivo é garantir que cada etapa do desenvolvimento contribua para a construção de um projeto eficiente, bem elaborado e de qualidade.
